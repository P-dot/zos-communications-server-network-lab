# Image sanitization notes

The lab uses screenshots extracted from the submitted evidence document. They are included only as supporting evidence for the planning exercise.

Public repository guidance:

- Do not upload the original DOCX evidence file.
- Use this sanitized lab package instead.
- Review screenshots before publishing and mask any site-specific IP addresses, hostnames, user IDs or non-sample network values if visible.
- This lab intentionally avoids showing any private certificate material or active keyring content.
